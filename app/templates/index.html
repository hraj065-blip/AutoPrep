WHY AN AGENT

More than a one-shot cleaning script

The agent adds context, feedback, and governed decisions around the transformations. The benchmark reports those behaviors separately from cell accuracy.

A

It observes before acting

Profiles types, missingness, duplicates, sentinels, and formatting. Proposals cite measured evidence instead of applying every cleanup rule to every file.

B

It checks its own work

Each action runs through a deterministic tool and a separate validator. Validation feedback informs the next planning pass; rejected actions can be revised within a bounded step budget.

C

It knows when to ask

Duplicate removal, imputation, and placeholder treatment stay behind explicit policy and human approval. The agent can recommend; it cannot authorize itself.

D

It leaves proof behind

Operation hashes, changed-cell evidence, row lineage, replay checks, and an audit export make the result explainable after the workflow ends.
